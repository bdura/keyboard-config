# Wiki index

Knowledge base for this project. Entry point: follow a hub page to reach everything
else.

This repository holds a personal [QMK](https://qmk.fm) configuration, kept as a
QMK external userspace. It currently targets a single keyboard: the Ferris
(34-key split).

## Hubs

- [[ferris-keymap]] — the `bdura` keymap for the Ferris: layers, thumbs, mods,
  combos and firmware settings.
- [[tooling]] — how the firmware is built and formatted: QMK userspace, Nix dev
  shell, formatters.
